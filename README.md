# «Второй я»: ИИ-ассистент на Telegram + Google Таблицах + Claude

Личный ассистент, который работает **у тебя на компьютере** и ведёт себя как твой «второй я»: знает всё, что есть в твоём Telegram, и никогда ничего не забывает, — но **ничего не пишет от твоего имени**.

1. **Скачивает историю всех твоих чатов** (личные, группы, «Избранное», архивная папка) в локальный архив и **изучает её**: что за работа, кто есть кто, водители, брокеры, клиенты, договорённости и обещания, как ты общаешься с разными людьми. Новые чаты подключаются сами.
2. **Читает Google Таблицы** и понимает, где и когда каждый водитель закончит груз и когда освободится.
3. **Каждый день присылает отчёт** в Telegram: по водителям, кто где освобождается, риски, что изменилось, что сделать сегодня.
4. **Напоминает**: по твоей просьбе («напомни в 15:00 запросить апдейт у Ивана»), по расписанию и сам — перед выгрузками.
5. **Следит за чатами в фоне**: новые сообщения сразу попадают в архив, ассистент запоминает важное и пишет тебе, если водитель сообщил о проблеме, изменился план и т.п.
6. **Помнит всё**: полный архив переписки с поиском (удалённые сообщения остаются с пометкой, у изменённых сохраняется старый текст) + база заметок (люди, водители, траки, договорённости, обещания, правила) + профиль + все прошлые разговоры с тобой. Каждую ночь сам дочитывает новое и пополняет память.
7. **Только чтение**: доступ к твоему Telegram ограничен в коде — ассистент технически не может отправить, переслать, удалить, отредактировать сообщение или отметить его прочитанным. Он говорит только с тобой — через своего бота — и может подготовить черновик ответа «как написал бы ты», но отправляешь ты сам.

Общаешься с ним через своего Telegram-бота — обычным текстом, можно присылать фото и PDF (рейт-коны, BOL, скриншоты) и пересылать сообщения.

> Мозг ассистента — модель **Claude Opus 5.5** (Anthropic). Все данные (архив, память, отчёты) хранятся локально в папке `data/`; в Claude отправляется только то, что нужно для конкретного ответа.

## Как это устроено

```
Telegram (твой аккаунт) ──► архив сообщений (SQLite + полнотекстовый поиск) ─┐
Google Таблицы ───────────► чтение + снимки для поиска изменений ───────────┤
                                                                             ├──► Claude + инструменты ──► ответы, отчёты,
Память: заметки + профиль работы (data/profile.md) + диалог ────────────────┘                             напоминания
Telegram-бот ◄──► ты
```

Claude не «угадывает»: на каждый вопрос он сам ищет по архиву, читает нужные листы таблицы, смотрит память — и только потом отвечает.

## Установка (Windows)

### 1. Python
Скачай Python 3.11 или новее: https://www.python.org/downloads/
При установке **обязательно отметь галочку «Add python.exe to PATH»**.

### 2. Скачай проект
Либо `git clone`, либо на GitHub: **Code → Download ZIP** и распакуй, например, в `C:\assistant`.

### 3. Установи библиотеки
Дважды кликни **`install.bat`**. Он создаст окружение `.venv`, поставит библиотеки и создаст файлы `config.yaml` и `.env`.

### 4. Ключи Telegram (чтобы скачать историю)
1. Зайди на https://my.telegram.org → войди по номеру телефона.
2. **API development tools** → создай приложение (название любое, платформа Desktop).
3. Скопируй `api_id` и `api_hash` в файл `.env`:
   ```
   TG_API_ID=1234567
   TG_API_HASH=abcdef0123456789...
   ```

### 5. Бот для общения
1. В Telegram открой **@BotFather** → `/newbot` → придумай имя → получишь токен.
2. Впиши токен в `.env`: `BOT_TOKEN=123456:ABC...`
3. Открой своего бота и нажми **Start** (иначе бот не сможет тебе писать).

Отвечает бот **только тебе** (владелец = аккаунт, под которым ты выполнишь `login`).

### 6. Ключ Claude
1. https://console.anthropic.com → зарегистрируйся → **Billing** → пополни баланс (например, $20).
2. **API Keys** → Create Key → скопируй в `.env`: `ANTHROPIC_API_KEY=sk-ant-...`

### 7. Google Таблицы (сервисный аккаунт — делается один раз, ~10 минут)
1. Открой https://console.cloud.google.com → создай проект (любое имя).
2. **APIs & Services → Library** → включи **Google Sheets API** и **Google Drive API**.
3. **APIs & Services → Credentials → Create credentials → Service account** → любое имя → Done.
4. Открой созданный сервисный аккаунт → вкладка **Keys → Add key → Create new key → JSON**. Скачается файл.
5. Положи его в папку проекта: `credentials\google-service-account.json`.
6. Открой файл, найди строку `"client_email": "...@....iam.gserviceaccount.com"` — это адрес «робота».
7. **В каждой нужной таблице**: кнопка «Настройки доступа» → добавь этот адрес как **Читатель**.

> Альтернатива: `auth: oauth` в `config.yaml` — вход своим Google-аккаунтом через браузер (нужен OAuth Client ID типа Desktop, JSON кладётся туда же). Тогда расшаривать таблицы не нужно.

### 8. Настрой `config.yaml`
Открой блокнотом и заполни:
- `timezone` — твой часовой пояс (`Europe/Moscow`, `America/Chicago`, …);
- `telegram.chats` — по умолчанию `all` (все чаты). Каналы и боты выключены (`include_channels`, `include_bots`), ненужные чаты можно исключить списком `exclude_chats`. Если вместо `all` указать список чатов, ассистент будет видеть только их (и чаты, скачанные командой `download --chat`);
- `google.sheets` — ссылки на таблицы и короткое описание, что в них (не нужны — оставь как есть);
- `report.time` и `report.instructions` — когда и что должно быть в ежедневном отчёте.

Под себя и свою работу (необязательно, но очень помогает):
- `assistant.about` — кто ты и чем занимаешься, своими словами; `assistant.instructions` — твои правила для ассистента («отвечай коротко», «время по Чикаго», «если водитель молчит 4 часа — напоминай»). Это учитывается в каждом ответе.
- `commands` — свои команды для бота: `/free`, `/late`, `/todo`, `/waiting` уже есть в примере, добавляй свои (имя латиницей). После команды можно дописать уточнение: «/free завтра после обеда». Они появятся в меню бота.
- `schedule` — свои задачи по расписанию: например, вечерняя сводка в 19:00 по будням или итоги недели в пятницу.
- `telegram.proxy` — если Telegram у тебя работает только через VPN/прокси (SOCKS5, HTTP или ссылка на MTProto-прокси `t.me/proxy?…`).

Опечатки не страшны: «да/нет» можно писать по-русски, дни недели — `[пн, ср, пт]`, `пн-пт`, `будни` или `выходные`, время — `8:30` или `8.30`. Если значение непонятно (например, `media_max_mb: много`), ассистент возьмёт стандартное и напишет об этом в боте и в `doctor`.

Перед первым запуском дважды щёлкни **`doctor.bat`** — он проверит Python, ключи, вход в Telegram, бота, Claude, таблицы и прямо скажет, что исправить.

### 9. Первый запуск
Просто запусти **`start.bat`** (двойным щелчком). При первом запуске он всё сделает по порядку:

1. **Вход в Telegram** — номер телефона, код из приложения Telegram, пароль 2FA (если есть).
2. **Скачивание всей истории** всех чатов — с прогрессом в окне и в боте («чат 12 из 340…»). Может занять от нескольких минут до пары часов; если прервать — продолжит с того же места.
3. **Изучение истории** — покажет, сколько сообщений и примерную стоимость, и спросит: ответь «да» в окне программы или `/learn_yes` боту. Ассистент разберёт всю переписку, составит память и профиль и пришлёт тебе, как он понял твою работу.
4. **Работа** — бот отвечает на вопросы, присылает отчёты, напоминает, следит за новыми сообщениями.

Пока идут шаги 2–3, бот на любое сообщение отвечает, на каком он этапе. При следующих запусках он сразу начинает работать, а пропущенное докачивает в фоне.

Отдельные команды (не обязательны — `start.bat` делает всё сам). Их запускают в командной строке в папке программы: в проводнике в адресной строке напиши `cmd` и нажми Enter.

| Команда | Что делает |
|---|---|
| `assistant.bat login` | только вход в Telegram |
| `assistant.bat chats` | список всех чатов и что с каждым будет: «✓ берём» или почему пропущен |
| `assistant.bat download` | только скачать/докачать историю |
| `assistant.bat sheets` | проверить доступ к таблицам |
| `assistant.bat learn` | только изучить историю и таблицы (покажет стоимость и спросит) |

Скачать только один чат: `assistant.bat download --chat "Название чата"`. Каналы: поставь `include_channels: true` в `config.yaml` (или разово `assistant.bat download --include-channels` — скачанные так каналы ассистент запомнит и будет вести дальше).

После изучения открой **`data\profile.md`** — это профиль, который ассистент составил по всей переписке: кто ты, твоя работа, люди, процессы, открытые обещания, твой стиль общения. Его можно поправить блокнотом: ассистент читает его перед каждым ответом.

### Автозапуск вместе с Windows
`Win+R` → `shell:startup` → положи туда **ярлык** на `start.bat`. Если компьютер был выключен во время отчёта — отчёт придёт сразу после запуска, пропущенные сообщения докачаются.

### Если что-то упало
`start.bat` сам перезапускает ассистента после сбоя (через 30 секунд), а бот потом пишет, что случилось. Подробности сбоя сохраняются в **`data\crash.log`**. Если проблема в настройках (неверный ключ или токен, программа уже открыта в другом окне) — перезапуска не будет: в окне написано, что исправить. Проверить всё сразу — **`doctor.bat`**.

### macOS / Linux
```bash
./install.sh
./doctor.sh          # проверка
./assistant.sh run   # основной режим (сам войдёт, скачает, предложит изучить)
```

## На сервере (24/7)

Чтобы ассистент был на связи всегда — даже когда компьютер выключен, — его ставят на сервер (VPS). Переносится всё: архив переписки, память, профиль, настройки и вход в Telegram — заново входить, скачивать и платить за изучение не нужно.

**1. Сервер.** Подойдёт любой недорогой VPS (обычно $5–10 в месяц): **Ubuntu 24.04** (или 22.04 / Debian 12), **2 ГБ памяти**, от **20 ГБ диска**. Выбирай расположение, откуда Telegram и Claude работают без VPN. После покупки у тебя будет адрес (IP) и пароль от пользователя `root`.

**Перед переносом — проверь на компьютере** (5 минут, сэкономит час на сервере):
- [ ] `doctor.bat` — всё ✅ (ключи, вход в Telegram, бот, Claude, таблицы);
- [ ] в `config.yaml` указан `timezone` — твой часовой пояс, а не сервера;
- [ ] история скачана и изучена, бот отвечает на вопросы (тогда на сервере ничего не придётся повторять и оплачивать заново);
- [ ] у бота нажат Start — иначе он не сможет писать тебе с сервера;
- [ ] сервер куплен, есть его адрес и пароль root, и из той страны, где он стоит, работают Telegram и Claude.

**2. Перенос (с компьютера на Windows):**
1. Закрой окно `start.bat` — ассистент не должен работать в двух местах сразу (скрипт это проверит и сведёт базу в один файл, чтобы копия архива была целой).
2. Дважды щёлкни **`deploy\upload_to_server.bat`**, введи адрес вида `root@203.0.113.10` и пароль от сервера (спросит пару раз).
3. Сервер сам всё установит. Если в `config.yaml` не указан часовой пояс — спросит его (на сервере часы в UTC, без этого отчёты придут не вовремя).
4. В конце бот напишет «✅ Я на связи».

На компьютере ассистент после переноса отключается (появится файл `data\MOVED_TO_SERVER.txt`): если случайно запустить `start.bat`, он не запустится — два запуска с одним входом в Telegram ломают сессию.

**3. Управление на сервере.** Подключись: в Windows Terminal набери `ssh root@АДРЕС`, затем:

| Команда | Что делает |
|---|---|
| `tg-assistant status` | работает ли и что в архиве |
| `tg-assistant logs` | что он делает прямо сейчас (выход — Ctrl+C) |
| `tg-assistant doctor` | проверить всё |
| `tg-assistant config` / `tg-assistant env` | поправить `config.yaml` / ключи, потом `tg-assistant restart` |
| `tg-assistant restart` / `stop` / `start` | перезапустить / остановить / запустить |
| `tg-assistant login` | войти в Telegram заново |
| `tg-assistant profile` | посмотреть/поправить, как ассистент понял твою работу |
| `tg-assistant learn` / `chat` | изучить историю / поговорить прямо в консоли сервера |
| `tg-assistant backup` | резервная копия (делается и сама каждый день, хранятся 14 последних) |

Ассистент работает как служба: сам запускается после перезагрузки сервера и перезапускается после сбоя. Что сделано для работы 24/7:
- **обрыв связи** — служба перезапускается через 30 секунд и докачивает пропущенное; один и тот же сбой бот сообщает не чаще раза в 3 часа, чтобы не засыпать сообщениями;
- **если нужно твоё участие** (вышли из сессии Telegram, неверный ключ, ошибка в настройках) — служба не крутится вхолостую, а **бот пишет тебе в Telegram, что случилось и что сделать**;
- **раз в 30 минут** ассистент сверяется с Telegram и докачивает то, что не пришло в реальном времени (`telegram.resync_minutes`);
- **изучение истории идёт только одно** — кнопка в боте, ночное изучение и `tg-assistant learn` не запустятся одновременно и не оплатят одно и то же дважды;
- **права на файлы** поправляются сами при `tg-assistant start/restart`, а `doctor` проверяет свободное место на диске.

**4. Обновление.** Скачай новую версию на компьютер и снова запусти `deploy\upload_to_server.bat`. Обновится только программа: архив, память и настройки на сервере остаются (скрипт спросит, заменить ли `config.yaml` твоим).

**Безопасность.** На сервере лежит доступ к твоему Telegram — поставь серверу надёжный пароль (лучше вход по SSH-ключу) и никому его не давай. Ассистенту не нужны открытые порты: он сам ходит в Telegram и Claude. Файлы с ключами и сессией доступны только служебному пользователю `tg-assistant`.

*Без Windows:* скопируй папку проекта на сервер (`scp -r`) и выполни там `sudo bash deploy/install_server.sh папка_проекта`.

**Вернуть ассистента на компьютер:** на сервере `tg-assistant stop`, затем на компьютере удали `data\MOVED_TO_SERVER.txt`. Свежий архив сначала скачай с сервера (резервная копия в `/var/backups/tg-assistant`).

## Как пользоваться

Ассистент не просто отвечает, а помогает решать: видит проблему — сразу предлагает варианты, свою рекомендацию и первый шаг (с готовым черновиком сообщения), а в конце ответа коротко подсказывает то, о чём ты не спросил, но что важно сейчас («💡 Иван освобождается завтра в 14:00 — следующего груза пока нет»). Если видит, что что-то легко упустить, сам ставит напоминание и говорит об этом. Кроме твоей переписки он пользуется своими знаниями (логистика, ставки, документы, правила) и **может искать в интернете**: погода и дороги, расстояния, сведения о брокерах (MC/DOT), адреса и часы работы складов (`claude.web_search`, каждый поиск ≈ $0.01). Единственное, чего он не делает, — ничего не отправляет от твоего имени: твой Telegram для него только на чтение, ответы он готовит черновиками.

Пиши боту как самому себе, который всё помнит:
- «Где сейчас Иван и когда выгружается?»
- «Кто освобождается завтра и где?»
- «Что писал брокер по грузу 48213?»
- «Кто ждёт от меня ответа?»
- «Что я обещал Марии на прошлой неделе?»
- «Набросай ответ брокеру — как бы написал я» (черновик — отправляешь сам)
- «Что я тебе говорил про Петра?»
- «Напомни в 15:00 запросить апдейт у Сергея»
- «Каждый будний день в 9:30 напоминай проверить документы»
- «Запомни: Пётр не ездит в Нью-Йорк, трак 512»
- «Водитель опаздывает на выгрузку на 3 часа — что делать?»
- «Как поторговаться с брокером по этому грузу? Какая ставка нормальная на Даллас — Атланта?»
- «Проверь брокера XYZ Logistics — можно с ними работать?»
- переслать сообщение водителя: «что тут не так?»
- фото/PDF рейт-кона: «проверь, совпадает ли с таблицей»

Команды бота:

| Команда | Что делает |
|---|---|
| `/advice [тема]` | разбор: что горит, что может сорваться, кто ждёт ответа, где теряются время и деньги — и что с этим делать (например, `/advice простои`) |
| `/report` | отчёт прямо сейчас (с решениями по каждой проблеме и блоком «💡 Предложения») |
| `/check` | проверить новые сообщения и таблицы сейчас |
| `/reminders` | активные напоминания |
| `/memory [текст]` | что ассистент помнит (или поиск по памяти) |
| `/new` | начать новую тему (контекст разговора сбросится, память останется) |
| `/download` | скачать/докачать историю всех чатов (с прогрессом) |
| `/learn` | изучить неизученную историю (сначала покажет стоимость) |
| `/status` | состояние: архив, память, таблицы |
| `/usage` | расходы на Claude за сегодня и за месяц |

Команды в консоли: `assistant.bat chat` — поговорить без бота, `assistant.bat report` — отчёт в консоль, `assistant.bat status` — состояние и расходы. Отчёты также сохраняются в `data\reports\`.

## Память — как ассистент «помнит всё»

| Что | Где | Как используется |
|---|---|---|
| Вся переписка всех чатов | `data/assistant.db` (архив + полнотекстовый поиск, понимает разные окончания слов) | ищет и читает по запросу; твои сообщения подписаны «Я» |
| Удалённые и изменённые сообщения | та же база | удалённое остаётся с пометкой «УДАЛЕНО», у изменённого виден старый текст. Если программа была выключена — при запуске подтягиваются правки и удаления за последние `reconcile_days` дней (по умолчанию 3) |
| Заметки (люди, водители, брокеры, обещания, правила) | та же база | всегда перед глазами у модели; пополняются сами |
| Профиль | `data/profile.md` | читает перед каждым ответом |
| Снимки таблиц | та же база | видит, что изменилось за сутки/неделю |
| Все разговоры с тобой и отчёты | та же база | последние ~20 сообщений — в контексте, остальное находит поиском |

Как память пополняется:
- **сразу** — новые сообщения попадают в архив в реальном времени, новые чаты подключаются сами;
- **каждый час** — фоновая проверка запоминает важное и пишет тебе, если нужно твоё внимание;
- **каждую ночь** (`learn.nightly`) — ассистент изучает новое за день и пополняет память, раз в неделю обновляет профиль. Ночное изучение включается после первого ручного `learn`. Без вопросов изучаются только чаты, которые ты одобрил ручным `learn` (их новые сообщения), и небольшие чаты, появившиеся уже после этого (кто-то новый написал); не больше `nightly_max_chunks` частей за ночь (с настройками по умолчанию — максимум около $7, обычно гораздо меньше). Обо всём остальном — чатах, которые ты не выбирал, большой истории новой группы — ассистент напишет тебе со стоимостью и подождёт ручного `learn`.
- если тебя удалили из группы или ты из неё вышел — новых сообщений оттуда не будет, но всё скачанное раньше остаётся в памяти и доступно ассистенту.
- старые версии заметок памяти не теряются: при изменении или удалении заметки прежний текст сохраняется, и ассистент находит его поиском.

`learn` можно запускать вручную повторно — изучается только новое. `learn --reset` — изучить всё заново, `learn --sheets-only` — только заново разобрать таблицы.

## Сколько это стоит

Оплата Claude — по факту использования (точные цифры: `/usage`). Порядок величин для модели Opus 5.5:

| Действие | Примерно |
|---|---|
| `learn` (разово, все чаты) | от $5 до $50+ — зависит от объёма истории; точную оценку покажет перед запуском. Дешевле: `learn --model claude-sonnet-5-5` |
| ночное дообучение | обычно $0.1–1 за ночь (сколько нового за день), потолок — около $7 (`nightly_max_chunks`) |
| вопрос в чате | $0.02–0.15 |
| ежедневный отчёт | $0.10–0.60 |
| фоновая проверка (раз в час, если есть новые сообщения) | $0.02–0.10 за проверку |

Как сэкономить (в `config.yaml`):
- `claude.model: claude-sonnet-5-5` — примерно в 2 раза дешевле;
- `claude.watch_model: claude-sonnet-5-5` — дешёвая модель только для фоновой проверки;
- `watch.interval_minutes: 120` или `watch.enabled: false`;
- `effort_*: low/medium` — меньше «думает», дешевле.

## Безопасность

- `data/user.session` — это **доступ к твоему Telegram-аккаунту**. Никому не передавай папку `data/` и файл `.env`.
- **Только чтение — на уровне кода.** Клиент Telegram пропускает только запросы чтения (`Get…`, `Search…`, `Resolve…`); отправка, пересылка, правка, удаление, «прочитано», «печатает», статус «в сети» блокируются до того, как запрос уйдёт в сеть. Сообщения не отмечаются прочитанными — собеседники не видят, что ассистент их читал. Единственное исключение — команда `login` (нужно получить код входа).
- Без `BOT_TOKEN` уведомления выводятся только в окно программы и в `data\notifications.log` — от твоего аккаунта не уходит ничего.
- Служебный чат «Telegram» (коды входа) и @BotFather (токены ботов) не скачиваются никогда. Номера банковских карт прячутся, прежде чем текст попадёт к Claude (`privacy.mask_card_numbers`).
- Всё хранится локально в `data/`. В Claude (Anthropic API) уходят только фрагменты, нужные для конкретного ответа или изучения (условия использования данных — на anthropic.com). Если какой-то чат не должен попадать в анализ — добавь его в `exclude_chats` (лучше по названию: исключение запоминается за этим чатом и не слетает, если чат переименуют или группа станет супергруппой): даже уже скачанный, он перестаёт быть виден ассистенту, не изучается и не отслеживается (файл архива остаётся у тебя на диске). Если чат уже успели изучить, факты из него остаются в памяти — убрать их можно, написав боту «забудь всё про …» (или найди заметки через `/memory`); профиль пересоберётся без этого чата при следующем ночном обновлении или `learn`.
- Google-таблицы читаются только на чтение.
- Если что-то пошло не так — в Telegram: Настройки → Устройства → завершить сеанс «TG AI Assistant».

## Частые проблемы

Сначала запусти **`doctor.bat`** — он сам найдёт большинство проблем.

- **Висит на «Подключаюсь к Telegram…», потом «Нет связи с Telegram»** — Telegram недоступен с компьютера. Если он работает у тебя только с VPN — включи VPN на компьютере или укажи прокси в `config.yaml` (`telegram.proxy`).
- **«Ассистент уже запущен в другом окне»** — закрой второе окно (или дождись конца команды в нём). На сервере — служба уже работает: `tg-assistant status`.
- **На сервере служба не запускается** — `tg-assistant start` покажет последние сообщения; подробнее — `tg-assistant logs` и `tg-assistant doctor`. Бот в таких случаях обычно сам пишет, что случилось.
- **«Сессия Telegram больше недействительна»** — удали `data\user.session` и запусти `start.bat`: он попросит войти заново.
- **«Неверный BOT_TOKEN»** — возьми токен у @BotFather (`/mybots` → бот → API Token), вставь в `.env` целиком, без кавычек.
- **Упал с непонятной ошибкой** — пришли файл `data\crash.log`.
- **«Telegram-аккаунт не подключён»** — запусти `start.bat`: он попросит номер и код.
- **Бот молчит** — нажми у бота Start; проверь, что `start.bat` запущен и окно не закрыто.
- **«Нет доступа» к таблице** — открой таблицу для адреса сервисного аккаунта (`assistant.bat sheets` покажет адрес).
- **«не задан ключ» / «неверный ключ» Claude** — проверь `ANTHROPIC_API_KEY` в `.env` и баланс на console.anthropic.com.
- **Скачивание идёт долго** — для большой истории это нормально (Telegram ограничивает скорость). Можно прервать (Ctrl+C) и запустить снова — продолжит с места остановки. Только свежее: `download --since 2025-01-01`.
- **Время в отчётах неверное** — укажи `timezone` в `config.yaml`.
- Подробный журнал — `data\assistant.log`.

## Структура проекта

```
assistant/
  __main__.py          команды: login, chats, download, learn, sheets, report, chat, run, status, doctor
  runtime.py           надёжный запуск: понятные ошибки, журнал сбоев, одна копия программы
  doctor.py            проверка настроек, ключей, Telegram, бота, Claude, таблиц
  config.py            настройки (.env + config.yaml)
  db.py                SQLite: архив, поиск, память, напоминания, отчёты, снимки таблиц, расходы
  telegram_archive.py  Telethon: вход, выгрузка истории, прослушивание новых сообщений
  sheets.py            Google Таблицы: чтение, формат для ИИ, поиск изменений
  llm.py               Claude API: вызовы, цикл с инструментами, учёт расходов
  tools.py             инструменты Claude (поиск, таблицы, память, напоминания, отчёты)
  brain.py             ядро: контекст, чат, отчёт, фоновая проверка
  learn.py             изучение истории → память и профиль работы
  jobs.py              расписание: напоминания, отчёт, наблюдение
  bot.py               Telegram-бот и основной режим
  prompts.py           инструкции для Claude
deploy/                сервер: install_server.sh, служба systemd, команда tg-assistant, upload_to_server.bat
tests/                 тесты (python -m unittest discover -s tests)
```
