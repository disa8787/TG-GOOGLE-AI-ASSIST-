# ИИ-ассистент для работы: Telegram + Google Таблицы + Claude

Личный ассистент, который работает **у тебя на компьютере**:

1. **Скачивает всю историю Telegram** из рабочих чатов в локальный архив и **изучает её**: что за работа, кто водители, брокеры, клиенты, как устроены процессы, какие бывают проблемы.
2. **Читает Google Таблицы** и понимает, где и когда каждый водитель закончит груз и когда освободится.
3. **Каждый день присылает отчёт** в Telegram: по водителям, кто где освобождается, риски, что изменилось, что сделать сегодня.
4. **Напоминает**: по твоей просьбе («напомни в 15:00 запросить апдейт у Ивана»), по расписанию и сам — перед выгрузками.
5. **Следит за чатами в фоне**: новые сообщения сразу попадают в архив, ассистент запоминает важное и пишет тебе, если водитель сообщил о проблеме, изменился план и т.п.
6. **Помнит всё**: полный архив переписки с поиском + база заметок (водители, траки, договорённости, правила) + профиль работы + контекст разговора с тобой.

Общаешься с ним через своего Telegram-бота — обычным текстом, можно присылать фото и PDF (рейт-коны, BOL, скриншоты) и пересылать сообщения.

> Мозг ассистента — модель **Claude Opus 5.5** (Anthropic). Все данные (архив, память, отчёты) хранятся локально в папке `data/`; в Claude отправляется только то, что нужно для конкретного ответа.

---

## Как это устроено

```
Telegram (твой аккаунт) ──► архив сообщений (SQLite + полнотекстовый поиск) ─┐
Google Таблицы ───────────► чтение + снимки для поиска изменений ───────────┤
                                                                             ├──► Claude + инструменты ──► ответы, отчёты,
Память: заметки + профиль работы (data/profile.md) + диалог ────────────────┘                             напоминания
Telegram-бот ◄──► ты
```

Claude не «угадывает»: на каждый вопрос он сам ищет по архиву, читает нужные листы таблицы, смотрит память — и только потом отвечает.

## Установка (Windows)

### 1. Python
Скачай Python 3.11 или новее: https://www.python.org/downloads/
При установке **обязательно отметь галочку «Add python.exe to PATH»**.

### 2. Скачай проект
Либо `git clone`, либо на GitHub: **Code → Download ZIP** и распакуй, например, в `C:\assistant`.

### 3. Установи библиотеки
Дважды кликни **`install.bat`**. Он создаст окружение `.venv`, поставит библиотеки и создаст файлы `config.yaml` и `.env`.

### 4. Ключи Telegram (чтобы скачать историю)
1. Зайди на https://my.telegram.org → войди по номеру телефона.
2. **API development tools** → создай приложение (название любое, платформа Desktop).
3. Скопируй `api_id` и `api_hash` в файл `.env`:
   ```
   TG_API_ID=1234567
   TG_API_HASH=abcdef0123456789...
   ```

### 5. Бот для общения
1. В Telegram открой **@BotFather** → `/newbot` → придумай имя → получишь токен.
2. Впиши токен в `.env`: `BOT_TOKEN=123456:ABC...`
3. Открой своего бота и нажми **Start** (иначе бот не сможет тебе писать).

Отвечает бот **только тебе** (владелец = аккаунт, под которым ты выполнишь `login`).

### 6. Ключ Claude
1. https://console.anthropic.com → зарегистрируйся → **Billing** → пополни баланс (например, $20).
2. **API Keys** → Create Key → скопируй в `.env`: `ANTHROPIC_API_KEY=sk-ant-...`

### 7. Google Таблицы (сервисный аккаунт — делается один раз, ~10 минут)
1. Открой https://console.cloud.google.com → создай проект (любое имя).
2. **APIs & Services → Library** → включи **Google Sheets API** и **Google Drive API**.
3. **APIs & Services → Credentials → Create credentials → Service account** → любое имя → Done.
4. Открой созданный сервисный аккаунт → вкладка **Keys → Add key → Create new key → JSON**. Скачается файл.
5. Положи его в папку проекта: `credentials\google-service-account.json`.
6. Открой файл, найди строку `"client_email": "...@....iam.gserviceaccount.com"` — это адрес «робота».
7. **В каждой нужной таблице**: кнопка «Настройки доступа» → добавь этот адрес как **Читатель**.

> Альтернатива: `auth: oauth` в `config.yaml` — вход своим Google-аккаунтом через браузер (нужен OAuth Client ID типа Desktop, JSON кладётся туда же). Тогда расшаривать таблицы не нужно.

### 8. Настрой `config.yaml`
Открой блокнотом и заполни:
- `timezone` — твой часовой пояс (`Europe/Moscow`, `America/Chicago`, …);
- `telegram.chats` — какие чаты скачивать (названия, `@username` или ID — см. шаг ниже);
- `google.sheets` — ссылки на таблицы и короткое описание, что в них;
- `report.time` и `report.instructions` — когда и что должно быть в ежедневном отчёте.

### 9. Первый запуск — по шагам
Открой командную строку в папке проекта (в проводнике в адресной строке напиши `cmd` и Enter):

| Команда | Что делает |
|---|---|
| `assistant.bat login` | вход в Telegram: номер, код из Telegram, пароль 2FA (один раз) |
| `assistant.bat chats` | список чатов с ID — выбери рабочие и впиши в `config.yaml` |
| `assistant.bat download` | скачать всю историю этих чатов (можно повторять — докачивает новое) |
| `assistant.bat sheets` | проверить доступ к таблицам |
| `assistant.bat learn` | ассистент изучает историю и таблицы (покажет примерную стоимость и спросит) |
| `start.bat` | основной режим: бот, отчёты, напоминания, наблюдение |

Скачать конкретный чат без правки конфига: `assistant.bat download --chat "Название чата"`. Все личные чаты и группы: `assistant.bat download --all`.

После `learn` открой **`data\profile.md`** — это «профиль работы», который ассистент составил по истории. Его можно поправить блокнотом: ассистент читает его перед каждым ответом.

### Автозапуск вместе с Windows
`Win+R` → `shell:startup` → положи туда **ярлык** на `start.bat`. Если компьютер был выключен во время отчёта — отчёт придёт сразу после запуска, пропущенные сообщения докачаются.

### macOS / Linux
```bash
./install.sh
./assistant.sh login
./assistant.sh download
./assistant.sh learn
./assistant.sh run
```

## Как пользоваться

Пиши боту как коллеге:
- «Где сейчас Иван и когда выгружается?»
- «Кто освобождается завтра и где?»
- «Что писал брокер по грузу 48213?»
- «Напомни в 15:00 запросить апдейт у Сергея»
- «Каждый будний день в 9:30 напоминай проверить документы»
- «Запомни: Пётр не ездит в Нью-Йорк, трак 512»
- переслать сообщение водителя: «что тут не так?»
- фото/PDF рейт-кона: «проверь, совпадает ли с таблицей»

Команды бота:

| Команда | Что делает |
|---|---|
| `/report` | отчёт прямо сейчас |
| `/check` | проверить новые сообщения и таблицы сейчас |
| `/reminders` | активные напоминания |
| `/memory [текст]` | что ассистент помнит (или поиск по памяти) |
| `/new` | начать новую тему (контекст разговора сбросится, память останется) |
| `/sync` | докачать новые сообщения |
| `/status` | состояние: архив, память, таблицы |
| `/usage` | расходы на Claude за сегодня и за месяц |

Команды в консоли: `assistant.bat chat` — поговорить без бота, `assistant.bat report` — отчёт в консоль, `assistant.bat status` — состояние и расходы. Отчёты также сохраняются в `data\reports\`.

## Память — как ассистент «помнит всё»

| Что | Где | Как используется |
|---|---|---|
| Вся переписка | `data/assistant.db` (архив + полнотекстовый поиск, понимает разные окончания слов) | ищет и читает по запросу |
| Заметки (водители, брокеры, правила, договорённости) | та же база | всегда перед глазами у модели; пополняются сами |
| Профиль работы | `data/profile.md` | читает перед каждым ответом |
| Снимки таблиц | та же база | видит, что изменилось за сутки/неделю |
| Разговор с тобой | та же база | помнит последние ~20 сообщений диалога |

Изучение истории (`learn`) можно запускать повторно — изучается только новое. `learn --reset` — изучить всё заново, `learn --sheets-only` — только заново разобрать таблицы.

## Сколько это стоит

Оплата Claude — по факту использования (точные цифры: `/usage`). Порядок величин для модели Opus 5.5:

| Действие | Примерно |
|---|---|
| `learn` (разово) | $2–15 в зависимости от объёма истории — точную оценку покажет перед запуском |
| вопрос в чате | $0.02–0.15 |
| ежедневный отчёт | $0.10–0.60 |
| фоновая проверка (раз в час, если есть новые сообщения) | $0.02–0.10 за проверку |

Как сэкономить (в `config.yaml`):
- `claude.model: claude-sonnet-5-5` — примерно в 2 раза дешевле;
- `claude.watch_model: claude-sonnet-5-5` — дешёвая модель только для фоновой проверки;
- `watch.interval_minutes: 120` или `watch.enabled: false`;
- `effort_*: low/medium` — меньше «думает», дешевле.

## Безопасность

- `data/user.session` — это **доступ к твоему Telegram-аккаунту**. Никому не передавай папку `data/` и файл `.env`.
- Ассистент **только читает** рабочие чаты и **не пишет** водителям/клиентам от твоего имени — он готовит информацию и тексты для тебя.
- Google-таблицы читаются только на чтение.
- Если что-то пошло не так — в Telegram: Настройки → Устройства → завершить сеанс «TG AI Assistant».

## Частые проблемы

- **«Telegram-аккаунт не подключён»** — выполни `assistant.bat login`.
- **Бот молчит** — нажми у бота Start; проверь, что `start.bat` запущен и окно не закрыто.
- **«Нет доступа» к таблице** — открой таблицу для адреса сервисного аккаунта (`assistant.bat sheets` покажет адрес).
- **«не задан ключ» / «неверный ключ» Claude** — проверь `ANTHROPIC_API_KEY` в `.env` и баланс на console.anthropic.com.
- **Скачивание идёт долго** — для большой истории это нормально (Telegram ограничивает скорость). Можно прервать (Ctrl+C) и запустить снова — продолжит с места остановки. Только свежее: `download --since 2025-01-01`.
- **Время в отчётах неверное** — укажи `timezone` в `config.yaml`.
- Подробный журнал — `data\assistant.log`.

## Структура проекта

```
assistant/
  __main__.py          команды: login, chats, download, learn, sheets, report, chat, run, status
  config.py            настройки (.env + config.yaml)
  db.py                SQLite: архив, поиск, память, напоминания, отчёты, снимки таблиц, расходы
  telegram_archive.py  Telethon: вход, выгрузка истории, прослушивание новых сообщений
  sheets.py            Google Таблицы: чтение, формат для ИИ, поиск изменений
  llm.py               Claude API: вызовы, цикл с инструментами, учёт расходов
  tools.py             инструменты Claude (поиск, таблицы, память, напоминания, отчёты)
  brain.py             ядро: контекст, чат, отчёт, фоновая проверка
  learn.py             изучение истории → память и профиль работы
  jobs.py              расписание: напоминания, отчёт, наблюдение
  bot.py               Telegram-бот и основной режим
  prompts.py           инструкции для Claude
tests/                 тесты (python -m unittest discover -s tests)
```
